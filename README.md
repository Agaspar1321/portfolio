# Portfolio

My portfolio site: four live projects, one of them built for a paying client.

**Live:** [andrewgasparportfolio.netlify.app](https://andrewgasparportfolio.netlify.app)

Plain HTML, CSS and JavaScript, no framework or build step. The project carousel is about 170 lines of vanilla JS, and with JavaScript off the page falls back to stacked project cards. The eleven desktop and phone screenshots are WebP, about 300 KB together.

Hosted on Netlify. Pushes to `main` deploy.

## Run it locally

Open `index.html`, or serve the folder with any static server:

```bash
npx serve .
```
