ShouldISlab →

Side project — Is grading this card worth the money?

Search a trading card and find out whether paying to have it professionally graded is worth the money. It pulls live sold prices, then runs a probability-weighted expected value: your odds at each grade against grading fees, seller fees, and what the raw card goes for today.

One verdict can cost 7 calls to a price API that allows about 10 every 35 seconds. I measured that limit and built an in-memory TTL cache around it; without the cache, the second search gets rate-limited. If a 429 still comes back, the server fails fast and shows a retry countdown. Grade odds come from population reports. Wilson score intervals keep a card with twelve graded copies from being trusted like one with twelve thousand.

  • Node.js
  • Express
  • REST API
  • Vanilla JS
  • Render
  • Cloudflare
